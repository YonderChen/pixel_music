## 几何样本

[构造器](./geometry-fixtures.cjs) 直接生成不透明 192×120 RGBA，不经过缩放。8 类：水平、上行、下行、波浪、间断、局部色块、双轨、独立像素噪声。三个条件：浅底黑线、深底彩线、低对比灰线；每类前两个校准，第三个保留。低对比条件仍是验收目标，不因困难移出样本。

[规范化后标注](./geometry-annotations.json) 固定每点 observed、方向、缺口及取舍：普通三像素竖向笔触取中心线，色块取顶部 y=40，双轨等证据取上方 y=36，杂乱噪声零可靠轨迹。间断缺口为半开 x=[52,64)、[112,124)，不得冒充实测点。标注来自图形构造，不是被测算法给自己生成的答案。

## 真实照片

[来源与许可](./photo-sources.json)、[像素与裁切记录](./photo-pixels.json)、[人工结构标注](./photo-annotations.json) 各自保留。来源是固定版 scikit-image 数据资源及 NASA 官方资源；每张记录上游 SHA、原尺寸、中心 cover 裁切、PNG／RGBA SHA、作者、来源页和许可页。NASA 资源仅用于本地信息性研发测试，保留署名，不假定宣传／商标或第三方肖像使用权。火星落日是官方假彩色摄影拼接，不称为单次原样曝光。

人工标注经逐张检查规范化接触表后制定。照片允许可靠轨迹或有理由回退；低信息 ROI 不是绝对没有任意边缘的二值真值，需检查每个点的真实局部支持、多尺度稳定和跨列连续性，禁止语义补线。不会拿人工指定音符为照片评分。

照片离线输入规范化版本为 `fixture-cover-pillow-bilinear-v1`，构建使用 Pillow 12.3.0。**这不是产品 Canvas 解码／缩放的等价实现**。测试固定已存 RGBA；后续浏览器快照应将配套规范化 PNG 1:1 解码并核对像素。Node 测试已独立解码 PNG 验证其与 RGBA 字节一致。用户正常上传仍用现有产品规范化，不改为 Pillow。

原始下载与接触表位于 Git 忽略的 `tests/artifacts/`；canonical PNG/RGBA 是固定公共测试夹具，需要保留。已有副本足以运行全部 M0 测试。仅在明确需要重建时执行：

```bash
node tests/m0/fetch-photos.cjs --download
python3 tests/m0/prepare-photos.py
```

重建是显式联网／写文件操作；需 Pillow 12.3.0。下载核对固定 SHA，TLS 验证开启。不得自动替换上游哈希以让错误资源通过；重建后必须重新核对 manifest，不能静默更新期望。不同 Pillow 版本、PNG 压缩或上游 CDN 改变时应报告差异。

## 保留集纪律

标注和分组在算法研发前固定。M0 查看素材做标注不是调参；本阶段没有检测器。只用校准集比较尺度、缺口、长度、强度等阈值。冻结候选参数后一次性运行保留集并保存失败；依据保留结果继续调参视作泄漏，需记录并补充新保留样本，不能反复换阈值后声称独立验证。

## 反例与关系检查

现有 legacy-60…71 纯色必须零轨迹；legacy-74/75 灰阶渐变不强制生线；legacy-81 相同颜色分布打乱和三个 geometry-noise 必须拒绝不可靠轨迹。其他有组织纹理不得仅因复杂被一概拒绝。

透明用补充控制例（不计入 120）：复制纯白，分别将全部 alpha 置零、仅第一个 alpha 置254，验证都显式回退，输入及旧摘要不被背景合成篡改。

M2/M3 增加条件受控的关系例：几何主轨迹上移8像素、右移8像素（不裁切），0.25拍网格下音高只升或不变、起点只后移或不变；固定种子±1亮度扰动不改变可靠性且同 x 的轨迹偏差 P95≤2 像素。扰动是新增鲁棒性目标，不代表 M0 已测算法稳定性。
