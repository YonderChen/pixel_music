# 图鸣 · PixelMusic

一个将图片像素确定性映射为音乐的网页版 MVP。所有图像分析和声音合成都在浏览器本地完成。

## 本地运行

在 `pixel_music` 目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 4173 -d dist
```

然后访问 `http://localhost:4173`。

## 当前能力

- 上传、拖放 JPG / PNG / WEBP 图片
- 规范化图片并生成 SHA-256 声音指纹
- 从色相、明度、饱和度和边缘密度生成固定旋律
- 三种浏览器合成音色
- 16 步扫描播放与音画同步
- 响应式移动端布局
