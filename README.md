# 图鸣 · PixelMusic

一个将图片像素确定性映射为音乐的网页版 MVP。所有图像分析和声音合成都在浏览器本地完成。

## 本地运行

直接双击打开 `dist/index.html` 即可使用，不需要安装依赖或启动服务。

如果浏览器限制本地文件，也可以在 `pixel_music` 目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173 -d dist
```

然后访问 `http://localhost:4173`。

## 当前能力

- 上传、拖放 JPG / PNG / WEBP 图片
- 规范化图片并生成跨运行环境一致的声音指纹
- 将图片划分为 24×5 个区域，为 120 个区域分别生成音符
- PixelMusic 0.3：每列五个区域沿蛇形路径逐音展开，全部 120 个区域进入同一条时间线
- 将音高收拢到约一个半八度，强拍选用当前和弦音，相邻音优先级进
- 每两列组成一个四拍小节，共 12 小节；长短节奏、重复动机、发展与主音收尾组成约 25～42 秒的乐曲
- 加入柔和和弦、低音伴奏、轻微空间回声及重叠尾音
- 点击图片中的任意区域，单独试听它对应的音符
- 三种浏览器合成音色
- 120 个区域逐音高亮，扫描动画按音频时间同步；自然结束保留尾音
- 响应式移动端布局

## 编曲检查

安装了 Node.js 的环境可运行 `node tests/music.test.cjs`，检查 432 组不同调式、主音与图像特征下的区域覆盖、节拍、和声、音高连续性和确定性。
