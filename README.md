# 图鸣 · PixelMusic

一个将图片像素确定性映射为音乐的网页版 MVP。所有图像分析和声音合成都在浏览器本地完成。

## 本地运行

直接双击打开 `dist/index.html` 即可使用，不需要安装依赖或启动服务。

如果浏览器限制本地文件，也可以在 `pixel_music` 目录启动仅本机可访问的静态文件服务器：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4174/dist/index.html`。监听项目根目录也能打开内部试听页；这不是在线发布。

## 当前能力

- 上传、拖放 JPG / PNG / WEBP 图片
- 将图片居中裁切、规范化为 192×120 像素，分别显示图像指纹与乐谱事件指纹
- 将图片划分为 24×5 个区域，为 120 个区域分别生成音符
- PixelMusic 0.5.0：每列五个区域沿蛇形路径逐音展开，全部 120 个区域各发声一次
- 16 小节、四个乐句：主题呈示 → 主题回应 → 中段发展 → 回归收束；每句 30 音
- 全图产生六个主题锚点，区域特征参与变奏；乐句束搜索控制音程、连接音、高潮与收尾
- 图片的空间变化、纹理组织、色彩转折和稳定区生成节奏动机；不再套用旧版固定整曲节奏
- 每小节动态分配 6–9 个音，生成长短音、重音与休止；每句仍为 30 音，不丢失区域
- 图片决定全局速度，允许 76–104 BPM、2 BPM 一档；本轮 60 图实际覆盖 76–94 BPM
- 平滑的乐句速度呼吸与终止放缓；本轮完整表达音频含尾音约 43–53 秒
- 三套和声进行与平滑转位；显式低音、铺底事件随本图结构变化，不再每小节机械重复；自然小调不额外引入升七级
- 乐句力度曲线与连奏／重复音／断奏／句尾释放，主旋律与伴奏使用不同的回声发送
- 点击图片中的任意区域，单独试听它对应的音符
- 暖键（默认）、晶体、弦雾三种本地合成音色，无在线音源
- 120 个区域逐音高亮，扫描动画按音频时间同步；自然结束保留尾音
- 播放中切换音色不重置进度或改变乐谱，响应式移动端布局
- 独立节奏指纹不包含音高或 BPM，可判断是否只是同一节奏换音高
- 在本机生成并保存完整音乐 WAV，不上传图片或音频

确定性约定是“相同规范化像素、作曲版本和设置 → 相同乐谱事件”。图片解码、缩放、色彩管理可能因浏览器而异；不承诺不同图片绝不撞谱，也不承诺最终 WAV 字节跨浏览器完全相同。摘要不是密码学哈希。

## 图片节奏对照

直接打开 `tests/rhythm-listen.html`，或点击工作台的“图片节奏 · 本地对照试听”。选择两张图，生成冻结的 0.4 与新版 0.5 共四段音频，匹配片段 RMS 响度。提供三个档：

- 只听节奏：统一 88 BPM、同音高、无伴奏，排除速度与音高干扰。
- 旋律与伴奏：保留各图音高和编曲，统一 88 BPM。
- 完整表达：恢复各图速度及新版的乐句呼吸。

历史 `tests/listen.html` 仍保留 0.3 → 0.4 的三档盲听与可选评分；使用冻结的 0.4 模块，不会因新版覆盖而失真。评分只在页面内存中，需手动导出，不上传、不自动代填。

按用户要求，本轮不以主观评分作为完成条件。自动测试能够证明节奏结构有差异、音乐约束和音频安全满足要求，不代表“所有人都觉得更好听”。

## 编曲检查

安装了 Node.js 的环境可运行：

```bash
node tests/music.test.cjs
node tests/rhythm.test.cjs
node tests/audio.test.cjs
node tests/timing.test.cjs
node tests/baseline.test.cjs
node tests/legacy.test.cjs
node tests/listening.test.cjs
node tests/local-bundle.test.cjs
node tests/browser-snapshot.test.cjs
```

九项测试覆盖 432 组新作曲参数、432 组旧算法参数、60 张规范化像素图、强制回退、变速时间轴与续播、180 组图像／音色排程（21,600 个区域事件）、0.3／0.4 金标准，以及 60 张真实浏览器乐谱快照。静态资源检查不冒充实时 `file://` 自动化：本地 HTML 的生成、播放和 WAV 保存已由用户确认。

新版对照页可运行 276 次真实 Web Audio 离线渲染，并生成指标报告；本轮全部通过。统一 88 BPM 后，原 12 图由旧版 1 种节奏变为 12 种；新增 48 图有 47 种节奏，不强制相似图全部不同。旧版 108 次回归仍保留在历史页。

无需 Node 即可使用主页面和试听页。本轮详情见 [RHYTHM_IMPLEMENTATION_REPORT.md](./RHYTHM_IMPLEMENTATION_REPORT.md)，机器可读结果见 [tests/rhythm-regression-summary.json](./tests/rhythm-regression-summary.json)。[IMPLEMENTATION_REPORT.md](./IMPLEMENTATION_REPORT.md) 保留为 0.4 历史报告。
