# 图鸣 · PixelMusic

一个将图片像素确定性映射为音乐的网页版 MVP。所有图像分析和声音合成都在浏览器本地完成。

## 本地运行

直接双击打开 `dist/index.html` 即可使用，不需要安装依赖或启动服务。

如果浏览器限制本地文件，也可以在 `pixel_music` 目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173 -d dist
```

然后访问 `http://localhost:4173`。

## 当前能力

- 上传、拖放 JPG / PNG / WEBP 图片
- 规范化图片并生成跨运行环境一致的声音指纹
- 将图片划分为 24×5 个区域，为 120 个区域分别生成音符
- 从左向右演奏每列区域琶音，生成约 15～20 秒的固定乐曲
- 点击图片中的任意区域，单独试听它对应的音符
- 三种浏览器合成音色
- 16 步扫描播放与音画同步
- 响应式移动端布局
