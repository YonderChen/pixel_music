# 图鸣 · 0.6.1 轻奏留白优化

日期：2026-10-07（北京时间）

状态：实现、工程验证与用户直接 HTML 功能验收完成。未在线发布。

## 1. 目标与取舍

把纯色／长时间稳定片段的连续蜂鸣，改为默认的稀疏、柔和同音重复：保留原音高与图片结构，用自然衰减和真实静音间隔表达。它是基础奏法规则，不宣称白色像素提供了额外节奏变化。

这是用户在完成 0.6 验收后提出的新方向，因此放开旧计划“纯色必须只有一次起音”的约束，但不恢复预设旋律、高潮、随机装饰或和弦循环。连续长音仍可在“连续声景”选项中使用。

## 2. 实现

- `melody` 继续保存图片决定的音高／结构片段，`regionMap` 保留全部 120 区域。
- 新增 `performanceEvents` 保存实际起音，`performanceRests` 保存奏法留白；每个事件标记来源片段及 `origin`。
- 只有片段至少 6 拍、平均复杂度不超过 0.08、特征漂移不超过 0.035 且没有测得周期重触发依据时，才采用轻奏。不是所有图片套同一拍型。
- 起音间隔按稳定片段的亮度／有效色度选择四分之一拍网格上的 3–3.5 拍；单音约 1–1.25 拍。所有同一片段的音高与力度一致，不加随机变化。
- 每个短音有柔和攻击、持续衰减和最终释放，不是把原来的平直蜂鸣硬切开。
- 轻奏片段的低音／铺底不持续穿过空隙，纯色仍没有新增伴奏。
- 图像边界休止与奏法留白分别记录。图像休止暂停扫描；奏法留白只停声音，区域扫描继续。
- 实时播放、途中换音色、区域短试听、离线 WAV 均使用实际演奏事件；在静音间隔换音色不会复活已结束的音符。
- 选择奏法会重算乐谱；若正在播放则停止，并提示重新开始。单纯切换音色仍接续原进度。

参数版本为 `sparse-pluck-v1`，作曲／合成版本显示 0.6.1。原图像特征分析、分组与 64 拍时间轴未改动。

实际起音数不再作为图像复杂度的替代指标。例如低信息片段轻奏时可能多次起音，这些明确标记为奏法事件，不是图片提供的新动机。
