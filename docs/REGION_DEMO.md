# 区域分割 · Demo 0.9

2026-10-16。把固定的矩形网格换成按图片内容分割的区域：一块颜色、质感一致的东西就是一个区域，再按可选的顺序依次发声。

## 打开

图片演奏页的"演奏组合"第一项"区域分割 / 柔和合成混音"（默认），或 `feature-music.html#regions-soft`。"分割方式"切换三种分割，"演奏顺序"切换五种顺序，"分行"选择 2／3／4 个声部。

## 三种分割方式（`scripts/segmentation.py`）

都在 192×120 的分析图上、以 Lab 色差计算，只依赖 NumPy，结果确定可复现。

| 方式 | 做法 | 特点 |
| --- | --- | --- |
| 方格种子 · 区域生长 | 16 px 方格中心为种子，平稳处先长；与区域平均色、与来路邻点的色差都在阈值内就并入；先做中值滤波以免纹理碎裂 | 最贴合物体，最忠实：简单的图区域少，复杂的图区域多 |
| 四叉树 · 分裂合并 | 先切到 3–6 px 的小方块，自下而上把颜色接近的四个子块并成大块；再把颜色相近（色差 < 阈值的一半）的相邻方块跨树合并 | 由方块拼成的不规则形状，平稳处大、细节处细 |
| SLIC 超像素 | 网格上放约 60 个中心，按颜色＋空间距离迭代聚类，再修正连通性、并入碎片 | 区域大小均匀，数量稳定 |

三者共同的后处理：小于 24 px 的碎块并入色差最小的邻区；颜色几乎一样的 SLIC 邻块合并。纯白图在三种方式下都只有 1 个区域。

## 区域如何成为音乐（`scripts/region_music.py`）

- **声部**：区域的纵向重心决定声部，上面的区域在高音声部（沿用参考条带优化版的八度布局与柔和音色：轻铃、暖键、柔拨弦、柔低音）。
- **显著度**＝0.55 × 区域内显著图均值＋0.3 × 与相邻区域的色差＋0.15 × √面积占比。
- **演奏顺序**（下拉选择）：

| 顺序 | 做法 | 《星月夜》相邻两音的平均跳跃（图宽＝1，区域生长） |
| --- | --- | --- |
| 视线游走（默认） | 每个声部从最显著的区域出发，每次走到"显著度 − 1.4 × 距离"最大的下一个区域 | 0.15 |
| 显著度分层 | 按显著度分三层，最醒目的一层先从左到右，再第二、第三层 | 0.21 |
| 从左到右 | 按重心从左到右；越显著越响、越长 | 0.08 |
| 全图一条路径 | 全图一条视线游走路径，当前区域在自己的声部发声，其他声部延续上一个音形成和声，画面只高亮一处 | 0.15 |
| 纯显著度 | 严格按显著度从高到低，不考虑位置（初版做法） | 0.39 |

- **时值**：与 √面积 成正比，最短 1/4 拍；声部内总长等于整曲长度。一个声部区域过多时，最不显著的区域不单独发声（选中时会说明）。
- **音高**：区域内像素的亮度、色相、饱和度、对比度、纹理沿用现有权重，按本图范围归一后吸附到音阶；保留音名，选择离上一个音最近的八度。
- **力度**：随显著度。暗区（亮度 < 0.03）休止。
- **伴奏**：由实际音符推出的和声铺底（同参考条带优化版）。

## 轮廓参与（开关，默认开启）

打开"轮廓参与"后，区域的形状也成为图片特征（`segmentation.shapes`）：

| 轮廓特征 | 计算 | 音乐 |
| --- | --- | --- |
| 边缘起伏 | 上边缘逐列高度（区域挂在图片顶边时改用下边缘，例如天空的山脊线），平滑后计总起伏 | 每 10 px 起伏多一个音；动机上限由高到低各声部为 4／3／3／2 个音；边缘越高音阶越高（±3 级，相邻音最多差 2 级），音名仍由区域颜色决定 |
| 圆润 / 尖锐 | 紧凑度 4πA/P²（正方形为 1） | 圆润连奏、音色柔；尖锐轻断奏（间隙不超过半拍）、音色略亮 |
| 边缘软硬 | 边界像素的边缘强度，在本图内归一 | 硬边缘起音快，柔和边缘缓慢起音 |
| 伸展方向 | 二阶矩主轴角度与伸展度 | 斜向（20°–70°）伸展、且末音不短于 1 拍时，向上或向下滑 1 个音阶；横向细长为长音 |
| 内凹 | 实心度 = 面积 / 凸包面积，本图最凹的 8 % 且 < 0.7 | 首音不短于 1 拍时前加倚音 |
| 包含 | 只与一个区域相邻且不贴图片边缘 = 被包围 | 被包围的区域发声时，外层区域的音名作持续低音 |
| 相邻 | 区域邻接图 | 同一声部里先后发声的相邻区域连奏衔接 |

轮廓参与时，区域时值与动机音都落在半拍网格上（最短半拍）。纯白图仍只有一个区域、一个长音。播放时画面以"边缘乐谱"呈现：发声区域退为淡色，被"读"的那条边缘画成虚线，点线是区域本音，每个动机音从点线拉出一根竖线到它在边缘上的取样点（越高音越高）；一支发光的笔随演奏沿边缘描过，笔到哪个点哪个音就响，并标出音名，已奏的点实心、未奏的点空心，滑音画成向上或向下的小箭头，被包围的区域发声时外层区域的轮廓以金色虚线呼吸表示持续低音；暂停时选中区域预览它的整段动机；选中区域显示紧凑、实心、方向与伸展。关闭开关即回到每个区域一个音。逐步的代码说明见 [CONTOUR_MUSIC.md](./CONTOUR_MUSIC.md)。

## 轮廓演奏方式（对比实验）

打开"轮廓参与"后多出一个"轮廓演奏方式"下拉框，四种方式可以切换试听对比，参考了 play_music_theory（playmusictheory.net）"横向是时间、纵向是音高"的线条演奏：

| 方式 | 做法 | 《星月夜》区域生长、4 声部 |
| --- | --- | --- |
| 起伏动机（默认，原版） | 上文的规则：边缘起伏成 1–4 个音的短动机 | 145 个音，滑音 7 处 |
| 量化取样 · 滑音 | 区域分到的时长按八分音符格切开（最低声部四分音符），每格读取对应那段边缘的高度，越高音阶越高（±4 级）；高度变化超过 1.25 级才换音，每次最多走两级；短于一拍的音并入音高最近的邻音，每个区域最多是动机上限的两倍；相邻一级且不超过全音的缓坡用滑音连过去。形状决定的断奏/连奏、音色、起音、倚音、包围低音不变 | 112 个音，滑音 14 处 |
| 线条演奏 · 横向时间纵向音高 | 不再按区域顺序：从所有区域的上边缘（挂在顶边的区域取下边缘）里挑出横跨画面至少 1/4、最清晰、与邻区色差最大的几条作主线（一个声部一条，重复的边界只留一条，贴画框的部分不发声）；主线断开的地方，由高度相近（相差不超过画高 30 %）的较短边缘接续，两拍以内的小断口延长前一个音。播放线从左到右扫过整张图，每个八分音符格读取线的高度，在三个八度的音阶上取音；同音延长、每小节重新起音，同一条边上相邻一级的缓坡滑音。最高的线进最高声部；演奏顺序选项此时不起作用，也没有包围低音 | 118 个音，滑音 57 处，全曲没有静音段 |
| 扫描线 · 竖线与分界交点 | 不分声部也不分行：一条竖线从左到右扫过整幅画，每个八分音符格读一列，竖线碰到的每一条区域分界线都发音，碰到几条就同时响几个音；只有落在同一个音阶音上的两个交点合成一个（取颜色差大的）。交点越高音越高（三个八度，吸附到音阶）；沿同一条分界线走、高度变化不到 0.6 级时延长原音，扫过区域侧边换到新的分界、高度明显变化或到新的一小节时重新起音，只响一格的同一分界高度抖动并入前一个音。分界两侧色差越大越响，分界下方区域的颜色决定音色（暖色或灰色暖键、黄色圆木琴、绿色和紫色柔拨弦、蓝色轻铃，低音区柔低音）。全部音符在一条"扫描线"轨道上，"分行"设置不起作用。画面上竖线扫过，交点发光并标出音名，持续的音随衰减变暗，扫过的分界留下区域颜色的轨迹，前方的乐谱以淡虚线预先显示 | 《星月夜》区域生长 296 个音，平均同时约 9 个、最多 14 个交点发声 |

滑音只在音尾约 0.18 秒内完成（缓入缓出），之前保持原音高，最多滑一个全音；四种方式的滑音（包括原版的斜向滑音）都按这个规则。滑音、起音快慢与音色明暗只在柔和合成混音里听得到。线条演奏时，图上会出现一条从左到右移动的播放线，正在发声的主线被描出来，光点标出当前音的位置。纯白图没有可用的边缘，退回一条横线、一个持续的音。代码在 `scripts/region_music.py`（`contourStyle` 选项，`contour_figure` 的量化分支与 `play_lines`）。

## 柔化轮廓（开关，默认开启）

分割写实地贴着像素走，边界多锯齿。打开"柔化轮廓"后：

1. **区域变圆滑**：对标签图做 3 次 5×5 多数滤波（每个像素取周围最多的区域，平局保留自己），磨掉台阶和毛刺；被切开的碎片重新连通、并入邻区。纯色图不受影响。《星月夜》区域生长的边界长度 3806 → 2918 px，SLIC 4490 → 3172 px。
2. **画成曲线**：沿像素边追踪每个区域的边界环，取边中点（先切掉台阶角）并以 Douglas-Peucker 简化（`segmentation.outlines`，每张图约 10 KB），浏览器再用 Chaikin 细分三次，按屏幕分辨率绘制平滑曲线；贴着画框的那段不描边。点击和移动试听仍按标签图逐像素判断。

关闭即回到写实的像素轮廓。柔化也让轮廓演奏更有条理（《星月夜》区域生长，轮廓参与）：

| | 柔化与节奏整理前 | 之后 |
| --- | --- | --- |
| 每秒音数 | 12.0 | 6.2 |
| 不在半拍网格上的起音 | 73 % | 4 %（仅倚音） |
| 短于半拍的音 | 57 % | 21 % |

## 界面

区域用画布描出轮廓；播放时发声区域按声部颜色高亮，其余区域变暗，音名标签浮在发声区域上方。点击区域试听、移动试听、独听与静音、WAV 导出、送入乐曲成画都可用。选中区域显示其显著度名次、重心、面积与特征。

## 验证

- `tests/segmentation.test.py`：形状特征（圆、横条、斜条、天际线）；三种方式纯白 1 个区域、结果可复现、编号连续、区域连通；渐变按竖条、棋盘 40 格。
- `tests/region-music.test.py`：3 张图 × 3 种分割 × 5 种顺序 × 轮廓开关 × 2／4 声部，另加三种新轮廓演奏方式 × 2 种顺序（线条演奏和扫描线检查每个声部从左到右）；每个声部按显著度顺序发声、音符不重叠、每个音只属于一个区域；纯白图是一个贯穿全曲的长音。
- 浏览器（Pyodide＋WASM）：三种分割切换、整曲、独听、移动试听、点击试听、送入乐曲成画（与原页 RMS 一致）。
- 原有组合回归（`horizontal-rows`、`soft-row-mix` 及 Node 客户端测试）不变。
- 效果对照图：`python3 scripts/segment_preview.py [细度]` → `artifacts/segmentation/`。
