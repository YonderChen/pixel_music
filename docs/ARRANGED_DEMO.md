# 编曲版与参考条带优化版 · Demo 0.8

2026-10-14。目标：在图片特征之上增加一层编曲规则，让多行叠奏更好听，并与现有三种组合 A/B 试听。

## 打开

图片演奏页的"演奏组合"中选择（当时是默认第一项，现在默认是 [区域分割](./REGION_DEMO.md)），或直接进入 `feature-music.html#arranged`。原三种组合与参考原谱保持不变。

## 改了什么

| 问题（原组合实测） | 编曲版做法 |
| --- | --- |
| 4 行挤在同一音区，57–100% 的同时发声是同度或二度 | 各行分担主旋律、副旋律、分解和弦、低音，分处不同八度；2 行为主旋律＋低音，3 行为主旋律＋分解和弦＋低音 |
| 特征加权和集中在中间，整首只用 2–3 个音 | 特征按本图中位数与分位数归一，旋律走向用满音区；纯色图仍接近平稳 |
| 一格一音的匀速节奏 | 纹理、对比与饱和度在全图中的相对强弱，按半小节选择二分、四分、附点或八分节奏型；每 4 小节一句，句尾长音换气，结尾回到主音 |
| 旋律与和弦无关 | 共用 4 小节和弦进行（饱和度、对比度选择进行），强拍落在和弦音；副旋律避开主旋律碰撞，低音奏根音与五音 |
| 每行自动从 80 种乐器中挑，常出现班卓琴＋风笛＋合唱 | 按明暗、冷暖与细节从 5 套固定配器中选择：木琴轻步、夜色弦乐、暖木室内乐、冷雾电钢、晨光钢琴 |
| 伴奏为风笛、打击 tick 等原项目伴奏 | 改为一份柔和的和弦铺底，声部平滑连接 |
| 各行独立归一后等量叠加 | 先对齐各声部响度，再按角色加权（主旋律 1、副旋律 .55、分解和弦 .5、低音 .62、铺底 .42），加入混响与声像 |

暗区（亮度 < 0.03）仍休止。图片区域依旧可点击、移动试听，每个音符保留来源区域。

## 修正：MIDI 时间编码

> GS 采样音源后来已移除，现在所有组合都用 Simple 合成；下面关于 GS 的测量与验证保留为当时的记录。

上游 `audio.py`（Python，已删除）的 `write_var_len` 只能正确写出小于 128 tick 的时间差，更长的时间差会被拉长约 60 倍。实测原"多特征音高转换 / 原有叠加"在 GS 音源下每行乐谱 88 个音，渲染出的音频只检测到 1–5 个起音，有的行 95% 时间无声；所有组合的 GS 整体伴奏也受影响。

当时编曲版渲染时临时换用 `scripts/arranger.py`（Python 版，已删除）中的标准 MIDI 写出（同时加入混响发送与声像），不修改固定的上游文件，原三种组合与参考原谱的声音保持原样，以便对照。

## 验证

- 两张样图，4 行：同度／二度碰撞 8–10%；旋律音域 12–17 个半音；强拍和弦音 91–95%；相邻同音 16%。
- 纯白、纯黑、渐变、噪声、上半黑图 × 2／3／4 行 × GS／Simple：生成、区域映射与渲染正常。
- 本机 FluidSynth 与浏览器 WASM：整曲、独听、移动试听，以及送入乐曲成画的回放均正常，后者与原页 RMS 一致。
- 好不好听仍以人工试听为准。

## 0.8.1 · 忠实度：每一处音乐变化都来自图片变化

人工试听反馈：编曲版好听，但纯白图也会"弹出花"。原因是和弦进行、分解和弦、句尾收束都由规则自行生成。现调整为：

- 和弦只在整条小节的图片特征变化时（加权变化 ≥ 0.015）才前进；图片不动，和弦不动。有过变化的曲子才在结尾回到主音。
- 节奏疏密以全图相对强弱为基础，再受纹理与对比度的绝对值封顶；几乎无纹理的区域只奏长音，分解和弦退为单个持续音。
- 区域特征不变（变化 < 0.012）时，同音连成长音（最长一小节），并优先保持原音高；明显变化（≥ 0.025）才鼓励旋律移动。
- 力度来自对比度与饱和度；乐句起伏的幅度随本行图片的变化量缩放。

结果：纯白图每行每小节一个长音，全曲一个和弦；名画仍保留 4–10 次和弦变化与旋律起伏。

## 新增：行内参考条带 · 优化 / 柔和合成混音

保留原"行内参考条带 / 柔和合成混音"作对照，新增优化版：

- 每个音的音名、起音、时值与旋律起伏完全沿用行内参考条带法，只按图片上下把整行移动八度（4 行：+12／0／−12／−24），上面的行更高。
- 音色按音区分配：轻铃（高）、暖键、柔拨弦、新增的柔低音（低）。
- 整体伴奏不再使用原项目自动生成的和弦进行与打击 tick，改为由各行实际奏出的音推断和弦的柔和铺底：每小节选与音符最吻合的和弦，只有明显更合适时才更换，不用减三和弦；同一和弦持续不重击。
- 铺底用修正后的 MIDI 时间编码渲染。

《星月夜》同时发声的近音（≤2 半音，含同度）由 48% 降到 12%；纯白图由 100% 降到 0，四行成为八度叠置的同一个音，伴奏只有一个和弦。

原三种组合的声音与乐谱不变（`horizontal-rows`、`soft-row-mix` 回归逐字节一致）。
