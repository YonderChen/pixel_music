# 乐曲成画 · Demo 0.1

2026-10-11。第一轮目标：让音乐生成可以独立观看的抽象画，同时保留可核对的音乐关系，交给人工判断观赏性。

## 使用

打开 [乐曲成画工作台](../dist/music-art.html)（在线版为 <https://pixel-music.pages.dev/music-art.html>）。页面先显示画作，声音在点击播放后准备。

1. 在“古典名曲 · MIDI”中选择《致爱丽丝》《C 大调前奏曲》《土耳其进行曲》《小狗圆舞曲》《月光》或《D 大调卡农》，也可切换三首原创演示样曲，看不同音乐的画面差异。
2. 同一首曲子切换“曲线色层”和“几何色块”（2026-10-17 起还有“扫描长卷”，见下文）。配色、细节与“换个构图”可以继续调整，正在播放的音乐保持原来的位置。
3. 点击播放，光点标出正在发声的画面位置。支持暂停、继续、进度拖动、从头播放和循环。
4. 保存 PNG（2400 × 1800）或 SVG。PNG 生成后保留预览和再次保存链接，也可以右键预览图片保存。导出的静态画作不包含播放光点。

在 [图片演奏页](../dist/feature-music.html) 的“保存 WAV”下方，新增“把当前乐曲画出来”入口。它将当前版本、启用声部与伴奏选择送入绘画工作台，并暂停原页的声音。旧的已打开页面需刷新后才显示新入口；本轮没有刷新正在使用上传图片的原页面。

工作台也支持导入 MIDI 或本工作台导出的乐谱 JSON。文件不超过 2MB，最长 3 分钟，最多 5000 个音符。MIDI 支持 0／1 型、常规 PPQ 计时、速度变化、音符力度、声部／乐器和延音踏板。MIDI 音源为本机乐谱合成试听，不承诺复现原文件的采样乐器；弯音等其它控制器尚未映射。此版不直接分析 MP3／WAV。

2026-10-14 新增六首古典 MIDI 候选。《致爱丽丝》《C 大调前奏曲》《小狗圆舞曲》使用完整 MIDI；其余三首使用开头 2 分 30 秒节选，标题与来源说明均有标记。候选随网页内嵌，本地双击与静态服务器均无需联网读取乐曲；“下载原始 MIDI”保留完整曲文件，超过 3 分钟的原版需自行节选后再导入。来源、编谱者及许可见 [古典 MIDI 清单](../dist/classical-midi/README.md)。

## 音乐如何成为画面

| 音乐关系 | 画面处理 |
| --- | --- |
| 音高与旋律变化 | 改变连续曲线或几何元素的伸展位置 |
| 起音、时长与停顿 | 决定排列、疏密、面积及曲线的断开 |
| 力度 | 改变色层厚度、几何面积与对比 |
| 速度 | 调整整体展开幅度 |
| 乐器与声部 | 区分形态、线条材质和层次；伴奏弱于主旋律 |

画面先有统一构图和留白，再容纳音乐细节。自动配色从音高统计选择有限的协调色组；也可手动选配色。曲线与几何都使用同一份音乐数据，不依赖随机噪声生成细节。密集事件按时间归纳，最多绘制主要 8 个声部，试听仍保留导入的全部音符。

进入绘画核心的数据只有音符、时间、力度、乐器、声部、声像、速度和时长。来源图片的像素、颜色、纹理、区域坐标和音符来源引用全部剔除。标题和原曲音频地址用于显示与试听，不参与构图。柔和混音的主声部使用实际柔和音色名称；原组合试听在浏览器里按同一份乐谱重新生成，不改写演奏算法。

同一乐谱与画面设置生成相同画作。音乐指纹帮助核对切换画风时是否仍使用同一首音乐，它不是加密校验或艺术质量评分。画面中的色彩、造型对应是我们选择的创作规则，不代表音乐的唯一视觉解释，也不能据此恢复原照片。

## 2026-10-17 · 参照图片演奏的优化

图片演奏一侧把轮廓演奏改成了“竖线从左到右扫过，碰到的每条分界都发声，交点高低定音高，区域颜色定音色”，播放画面只亮正在发声的交点并随声音衰减。乐曲成画这次按同样的思路反向处理：

- **新增“扫描长卷”画风**：横向是时间，纵向是音高（左侧标出各八度的 C）。每个声部的旋律取每一小段里最高的音，平滑成一条分界线，线下铺该声部的颜色，像照片里的区域；每个音都画成一段音条，不归并、不限 8 个声部。颜色由音色决定，和图片演奏扫描线的颜色→音色对照一致：暖键陶红、圆木琴麦黄、柔拨弦青绿、轻铃靛蓝、铺底弦乐雾紫、低音区深色；同一音色的几个声部用深浅区分。画下方的图例列出本曲用到的音色。
- **播放画面**：扫描长卷里，一条竖线随音乐从左到右扫过，还没奏到的部分罩一层淡纸色，扫过就露出原色；竖线碰到的音亮起并标出音名。三种画风里，亮度都按合成音色的起音、衰减、释音变化，声音弱下去点也跟着暗下去，不再整块闪亮闪灭；曲线色层和几何色块还会在每个声部最近几个音之间留一段渐隐的轨迹。暂停时画作完整显示，扫描长卷保留竖线位置。
- **出声更快**：乐谱合成试听原来一次性创建所有音的合成节点，未开始的节点也要参与离线渲染，古典曲点播放后要等 25–50 秒（Chromium 实测《致爱丽丝》23 秒、《D 大调卡农》49 秒）。现在每个音在开始前 2–4 秒才加入渲染，奏完即断开，同样三首约 1.7–2.4 秒出声。新旧两种方式渲染出的波形相对误差约 5×10⁻⁸，听感不变。

曲线色层、几何色块的静态画作没有改动（核心测试里的 SVG 哈希与之前一致）。

## 人工验收

- 单独看画：构图是否平衡，能否分清主次，留白是否合适，是否愿意保存。
- 对比音乐：舒缓、密集、交织的三首曲子，是否产生可辨认的视觉区别。
- 对照演奏：光点位置、声部数量和实际音乐是否吻合；切换画风、暂停和拖动是否正常。
- 比较风格：先用默认“均衡”细节，再试简约与丰富，判断是否需要更强或更克制的画面。
