## 体验入口

- [全图特征](http://127.0.0.1:4176/feature-music.html#full-pitch)：默认“多特征音高转换 · 新”和“连续滑接”，按原有蛇形顺序串成一条暖键旋律。
- [多行叠奏](http://127.0.0.1:4176/feature-music.html#pitch)：相同的音高转换方法，分成 2／3／4 行横向同时演奏，可逐行独听。连续滑接使用柔和合成风格。

两者共用音高映射与转换规则，采样网格和演奏顺序不同。“局部多特征法 · 旧”、参考条带法与参考原谱保留作为对照。旧链接仍可打开新版入口。

## 借鉴参考项目的哪一部分

[play_music_theory 浏览器乐器](https://playmusictheory.net/play) 将归一化的绘图高度转换为音阶或连续频率，并在音高改变时保持振荡器相位，通过快速吸附或平滑频率过渡连接声音。

本版用图片的多特征数值代替绘图高度，借鉴的是**音高数值如何转换为音阶与频率，以及相邻高低音如何衔接**。图片分析与音高目标由本地独立实现，参考项目本身不是照片识别工具。

## 当前映射

每个区域计算亮度、色相、饱和度、对比度与纹理，继续使用已有的五项权重，合成 0～1 的音高位置。灰色区域的色相贡献保持中性，饱和度会降低低饱和区域的色相影响。目标映射到全图共用调式的音域；区域坐标只用于读取顺序与来源高亮，不用于补出旋律。

| 环节 | 处理方式 |
| --- | --- |
| 清晰音阶 | 将目标吸附到最近音级，以约 2 ms 时间常数快速趋近目标；相邻片段持续连奏 |
| 连续滑接 | 保留量化前音高，在相邻音级之间插值，再以 20–90 ms 时间常数平滑趋近目标；允许中间音 |
| 高低音变化 | 新映射不沿用旧版五个半音跳进上限，也不因细微变化强行补一个音级 |
| 连续发声 | 相邻片段共用相位和包络，不为每个格子重新敲击；暗区休止后重新起句 |
| 伴奏与导出 | 整体伴奏沿用参考编曲，共用一份缓存；区域短试听和完整 WAV 使用当前方式，文件名记录全图／多行与奏法 |
| 打开页面 | 先显示图片和乐谱，点击试听后按需生成音频，支持取消和失败重试 |

音阶吸附会让小变化保持同音；连续滑接保留更细的变化。区域短试听用于听当前目标，完整播放用于判断前后音高的衔接。音色、混音与具体参数属于本地实现，不承诺与参考网站听感完全相同。

## 人工验收

1. 选“音高转换验收 · 多特征渐变”：明暗、颜色与纹理逐步变化，分别比较清晰音阶与连续滑接。
2. 试“等亮横向色带”和“同明暗纹理变化”，检查颜色、纹理是否仍影响实际音高。
3. 上传同一张图片，在全图单旋律和多行叠奏之间比较；先关闭伴奏，再恢复完整编曲。
4. 暂停、继续、区域短试听并保存 WAV；纯白保持同音，全黑且无伴奏时静音。

验证：[映射与实际声音](../tests/full-pitch-transition-report.json)、[全图及多行实际 HTTP 试听](../tests/full-pitch-transition-api-report.json)、[内置浏览器验收](../tests/feature-pitch-browser-report.json)。核心检查明确禁止调用轮廓重心函数，确认坐标不进入音高目标，覆盖颜色、纹理、单旋律整图来源、两种奏法、按需加载与一次性共享 GS 伴奏。听感由人工验收。
