# “轮廓参与”是如何参与演奏的

本文按代码逐步说明（对应提交 b5a07c9，行号随代码改动可能偏移）。简表见 [REGION_DEMO.md](../REGION_DEMO.md#轮廓参与开关默认开启)。“轮廓参与”只在演奏组合选“区域分割”时出现，默认勾选。

## 一句话结论

不开轮廓时，每个区域只奏 **一个音**：音名来自区域的颜色、明暗、对比和纹理，时值来自面积。
打开后，音名和时长的来源不变，但这一个音会被换成一个 **短动机**：区域边缘的高低起伏决定动机的旋律，区域形状决定奏法、音色、起音和滑音，被包围的区域还会额外带出一个持续低音。

## 开关怎么传到算法

- 前端复选框 `contourToggle` 在 `dist/feature-music-app.js:329` 作为 `contourMusic` 发给生成接口，切换时会重新生成（`dist/feature-music-app.js:461`）。
- 后端在 `scripts/region_music.py:98` 读取 `contourMusic`，为真时调用 `segmentation.shapes(labels)` 计算每个区域的形状特征（`scripts/region_music.py:99`）。
- 不开时走 `scripts/region_music.py:261-263`，一个区域一个音；开启时走 `contour_figure`（`scripts/region_music.py:265`）。

## 第一步：给每个区域算形状特征

`scripts/segmentation.py:346-392` 的 `shapes()` 在分割标签图上（最大 192×120 像素，`scripts/segmentation.py:19-25`）为每个区域算出：

| 特征 | 含义 | 代码 |
|---|---|---|
| 紧凑度 compactness | 4π·面积/周长²，正方形为 1，锯齿或细长趋近 0 | `segmentation.py:367` |
| 主轴角度 angle | 区域主方向，正值表示向右上方伸展 | `segmentation.py:372` |
| 伸展度 elongation | 圆或方为 0，越像细线越接近 1 | `segmentation.py:375` |
| 实心度 solidity | 面积/凸包面积，月牙形很低 | `segmentation.py:381` |
| 边缘轮廓 profile | 每一列取区域的上边缘高度；挂在画面顶边的区域（如天空）改取下边缘，也就是山脊线 | `segmentation.py:386-389` |
| 是否贴边 border | 区域是否碰到画框 | `segmentation.py:390` |

此外 `region_music.py` 里还补了两项：

- **边缘清晰度 edgeSharpness**：区域边界像素上边缘图的平均强度，在本图内归一化（`region_music.py:103-104`）。
- **包围关系**：一个区域只与一个邻区相接且不贴画框，就视为被那个邻区包围（`region_music.py:114`）。
- **内凹阈值**：本图实心度最低的 8 % 区域（且不超过 0.7）才算明显内凹（`region_music.py:106`）。

## 第二步：节奏网格变粗

开轮廓后，区域时长按 **半拍** 网格分配，最短半拍；不开时是四分之一拍（`region_music.py:19`、`region_music.py:143`）。所以每个声部最多容纳的区域数也减半，最不显著的区域会让位不单独发声（`region_music.py:144-148`）。

## 第三步：把边缘变成旋律动机（`contour_figure`，`region_music.py:154-205`）

1. **平滑边缘**：轮廓高度先做 5 点加权平滑，去掉像素抖动（`:159`）。
2. **决定音数**：边缘总起伏量每 10 像素加一个音（`MOTIF_STEP`，`:18`、`:160-161`）。上限按声部由高到低递减，4 声部时是 4/3/3/2 个音，高声部活跃、低声部安稳（`:21`）；同时不能超过区域时长能容纳的半拍数（`:162`）。
3. **在边缘上取点**：沿轮廓均匀取这么多个点（`:163`）。
4. **高度变成音阶级数**：取点处比边缘平均高度高多少（相对区域高度）换算成音阶上下级数，范围 ±3 级，相邻两音最多差 2 级（`:166-168`）。
5. **音名基准不变**：动机以原来那个区域音为中心，在当前调式音阶上上下走（`:169-170`）。所以颜色仍决定“在哪个音附近”，轮廓只决定“怎么起伏”。
6. **节拍对齐**：每个动机音的起点都对齐半拍（`:176`）。

## 第四步：形状决定奏法、音色、起音

| 形状 | 效果 | 代码 |
|---|---|---|
| 横向细长（伸展度 > 0.6 且角度 < 20°） | 几乎全长连奏，原因里写“横向舒展，长音” | `:172-173`、`:203` |
| 越圆润（紧凑度高） | 越接近连奏；越尖锐越轻断奏，音符之间最多留半拍空隙 | `:173`、`:190` |
| 越尖锐 | 音色越亮（`toneScale` 0.7–1.3，调整滤波截止频率） | `:174` |
| 边缘越清晰 | 起音越快、力度略强；边缘柔和则缓慢渐入（`attackScale` 约 0.35–2.8 倍） | `:175`、`:195` |
| 明显内凹（最凹的 8 %） | 动机前加一个 1/8 拍的倚音，比主音高一级，力度 0.75 倍；第一个动机音要够一拍才加 | `:181-185` |
| 斜向伸展（伸展度 > 0.55，角度 20°–70°） | 最后一个音向上（右上倾斜）或向下滑一级音阶，且不超过一个全音；最后那个音要够一拍才滑。滑音只在音尾约 0.18 秒内完成（`soft_row_mixer.py` 的 `GLIDE`），之前保持原音高 | `:197-202` |

动机里第 2 个音以后力度稍减 0.04，让第一个音成为重音（`:195`）。

## 第五步：区域之间的衔接

- 同一声部里，前后两个区域如果在图上相邻，前一个音会延长到下一个音开始，形成连奏（`region_music.py:268-271`）。“全图一条路径”顺序不做这一步，因为那个模式本来就让每个声部延续到自己的下一个音（`:192`、`:237`）。

## 第六步：包围关系产生持续低音

`region_music.py:278-294`：每当被包围的区域发声，就用包围它的外层区域的音名，在 C3 附近（MIDI 48–59）加一个持续低音。同一音高连续或重叠时合并成一个长音。音色是 GeneralUser GS 的 89 号暖音垫（`gm_089`），简易合成下是 `warm_pad`，力度 0.34。
这些低音并入伴奏层（`scripts/reference_music.py:646`），所以关闭“伴奏”时它们也一起不出（`reference_music.py:648`）。

## 哪种混音能听到全部效果

起音、音色明暗和滑音这三个逐音参数只在 **柔和合成混音** 里被读取（`scripts/soft_row_mixer.py:40-49`）。`scripts/` 中其他渲染路径不读取 `toneScale`、`attackScale`、`bend`，所以 **原有叠加** 混音下能听到动机旋律、断奏/连奏时值、倚音和持续低音，但听不到起音快慢、明暗和滑音（由代码推断，未做试听对比）。

## 画面上的对应

播放时，画面上叠一层"边缘乐谱"（`dist/feature-music-app.js` 的 `drawContours`）：被读取的那条边缘（上边缘或下边缘）画成虚线，点线是区域本音的高度，每个动机音从点线拉一根竖线到它的取样点（点位来自 `region_music.py:193`）；一支发光的笔随时间沿边缘描过，到达取样点时该音响起。滑音画成小箭头，被包围的区域发声时外层区域（`containedBy`）以金色虚线表示持续低音。选中区域时，说明文字会列出每条规则命中了哪些，例如“上边缘起伏成 3 个音的动机；轮廓尖锐，轻断奏；边缘柔和，缓慢起音”（`region_music.py:178-205`、`:274`）。

## 关闭时

回到每个区域一个音，时长网格回到四分之一拍，没有倚音、滑音和包围低音（`region_music.py:261-263`）。纯白图只有一个区域，开不开都是一个长音。
